# 名古屋市営地下鉄 一筆書き定期運賃計算ツール (Frontend & API)

このディレクトリは、アプリケーションのフロントエンド（Next.js）およびバックエンド（FastAPI）を含むメインプロジェクトディレクトリです。

詳細なアプリケーションの概要、技術スタック、およびローカルでの起動手順については、プロジェクトのルートにある [README.md (ルート)](../README.md) をご参照ください。

---

## ディレクトリ内の主なファイル

- `app/`: Next.js (App Router) によるユーザーインターフェース。
- `api/`: FastAPIによるバックエンドAPI。
  - `api/main.py`: 一筆書き経路探索アルゴリズムおよび運賃計算ロジックが含まれます。
- `vercel.json`: VercelにNext.jsとPython APIを同時にデプロイするためのルーティング定義ファイル。
